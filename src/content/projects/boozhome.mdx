# BoozHome: plataforma inmobiliaria con catálogo público y administración integrada

Desarrollo exclusivo para cliente · Prelanzamiento · Caso en esquema

## Contexto

BoozHome es una plataforma web desarrollada de forma exclusiva para un cliente
inmobiliario. Combina un catálogo público de propiedades con un panel administrativo para
gestionar el contenido. La aplicación está preparada y su publicación está a la espera de
la activación del dominio.

## Problema original

Pendiente de documentar el contexto del problema aportado por el cliente. No se infieren
necesidades ni motivaciones no confirmadas.

## Objetivos funcionales

- Catálogo y fichas públicas de propiedades.
- Contacto por WhatsApp.
- Panel administrativo de propiedades, imágenes, estados y usuarios.
- Analíticas de uso del catálogo.

## Mi participación

Pendiente de documentar de forma verificable, respetando la titularidad del cliente.

## Solución implementada

Catálogo público con renderizado en servidor y panel administrativo interactivo. El stack
declarado es .NET 10 / C# 14, ASP.NET Core Minimal APIs, Blazor WebApp (catálogo SSR y
panel InteractiveServer), PostgreSQL, Tailwind CSS y Docker.
