## Contexto

BoozHome es una plataforma web desarrollada de forma exclusiva para un cliente inmobiliario.
Combina un catálogo público de residencias en Paraguay con un panel administrativo para gestionar
el contenido y las propiedades.

El nombre comercial está autorizado. El dominio `https://boozhome.com.py/` fue adquirido, pero
todavía no se ha confirmado el funcionamiento público del sitio. El proyecto permanece en
prelanzamiento.

## Problema

El proyecto aborda la publicación y administración de un catálogo inmobiliario: fichas con
ubicación, precio, descripción y galería, además de un panel para mantener el contenido.

El contexto específico del cliente y sus motivaciones no forman parte de la información
confirmada para publicación. No se infieren necesidades ni resultados no documentados.

## Mi participación

El desarrollo tecnológico de BoozHome estuvo a cargo del autor. BoozHome es un proyecto exclusivo
del cliente; este caso no atribuye su titularidad a Oñondive.

## Solución

La plataforma incluye:

- Catálogo público de residencias.
- Fichas con ubicación, precio, descripción y galería.
- Contacto por WhatsApp como funcionalidad propia del producto.
- Panel administrativo de contenido y propiedades.

El contacto por WhatsApp pertenece a la experiencia del producto inmobiliario. No se utiliza
como canal de contacto profesional del autor en este portafolio.

## Arquitectura y stack

El stack declarado es .NET 10, C# 14, ASP.NET Core Minimal APIs, Blazor WebApp, PostgreSQL,
Tailwind CSS y Docker.

La aplicación utiliza Blazor WebApp con el catálogo público renderizado en servidor y el panel
administrativo con InteractiveServer. La persistencia se apoya en PostgreSQL y el despliegue se
prepara con Docker.

## Decisiones técnicas confirmadas

- Catálogo público con renderizado en servidor.
- Panel administrativo interactivo con Blazor InteractiveServer.
- Backend sobre ASP.NET Core Minimal APIs.
- Persistencia en PostgreSQL.
- Tailwind CSS para la interfaz y Docker para el entorno de despliegue.
- Contacto por WhatsApp integrado en el producto.

No se exponen diagramas de seguridad, estructura de autenticación sensible, credenciales ni
datos operativos del cliente.

## Estado actual

BoozHome está en prelanzamiento. El dominio fue adquirido, pero no se declara «en producción»
hasta comprobar el funcionamiento público, HTTPS y el contenido publicado.

## Limitaciones y evidencia

No se publican logos, capturas, teléfonos, datos de propiedades ni información del cliente sin
autorización. El dominio no se enlaza mientras no se verifique su disponibilidad pública.

No se publican métricas de uso, cantidad de propiedades, resultados comerciales ni fechas de
lanzamiento que no estén confirmadas.

## Evolución

La publicación del sitio queda supeditada a la activación y verificación del dominio, además de
las autorizaciones del cliente sobre el material que pueda mostrarse. No se anuncia una fecha de
lanzamiento.
