## Contexto

SGAA es una plataforma SaaS de auditoría y aseguramiento que se encuentra en producción. Su
origen es la primera solución comercial de escritorio, desarrollada en 2020; con el tiempo
evolucionó hacia una plataforma web, comercializada desde agosto de 2025.

La solución integra la gestión de auditorías, aseguramientos y consultorías. Fue diseñada con
la participación de profesionales de auditoría y de tecnología, combinando necesidades
funcionales del sector con decisiones de implementación.

## Problema

El trabajo de auditoría requiere coordinar clientes, encargos, equipos, fases, procedimientos,
supervisión y control de calidad. SGAA aborda esa complejidad en una sola plataforma, con una
arquitectura multiempresa y trazabilidad sobre el proceso.

El caso no detalla el proceso previo de cada organización ni cuantifica sus puntos de fricción:
esa información no forma parte de la documentación confirmada para publicación.

Se realizaron consultas funcionales con profesionales de auditoría para comprender las
necesidades del dominio.

## Solución

SGAA organiza el trabajo de auditoría a través de:

- Clientes, encargos, equipos y fases.
- Procedimientos y seguimiento por encargo.
- Supervisión y control de calidad.
- Una arquitectura multiempresa.

El flujo funcional permite recorrer el encargo desde su organización inicial hasta el
seguimiento y la revisión, manteniendo separadas las responsabilidades de cada etapa.

## Arquitectura y stack

El backend está construido con .NET 8 y ASP.NET Core Web API. Incluye Finbuckle, MediatR,
Ardalis, CQRS y ASP.NET Identity. El frontend utiliza Blazor y MudBlazor, y la base de datos es
SQL Server.

El entorno de despliegue se apoya en Linux Ubuntu, con Nginx como proxy inverso y la
configuración necesaria para publicar la aplicación. La plataforma opera con una arquitectura
multiempresa.

## Decisiones técnicas confirmadas

- Separación entre API y frontend, con ASP.NET Core Web API y Blazor.
- Uso de CQRS y MediatR para organizar casos de uso y operaciones.
- Identidad basada en ASP.NET Identity.
- Persistencia sobre SQL Server.
- Despliegue en Linux Ubuntu con Nginx como proxy inverso.

El detalle de la topología interna, las credenciales, las direcciones de servidor y los
mecanismos específicos de seguridad no se publican.

## Estado actual

SGAA está en producción. La versión web se comercializa desde agosto de 2025 y la aplicación de
escritorio de 2020 fue el punto de partida de esta evolución.

El producto continuará recibiendo soporte y mantenimiento. El desarrollo estratégico de nuevas
capacidades se concentra en AuditaPy, sin que ello implique el fin de SGAA ni una reducción de
su soporte.

## Resultados y evidencias

Los indicadores aprobados se presentan en el bloque de datos agregados de este caso. Fueron
proporcionados y autorizados por el propietario; no constituyen una auditoría externa. No existe
una fecha de corte confirmada para estas cifras.

Los indicadores operativos se limitan a las empresas registradas como tenants y a los
contribuyentes registrados entre ellas. No se publican nombres de empresas ni se afirma que los
contribuyentes sean únicos entre tenants.

El propietario autorizó asociar el dominio `redfor-ti.com.py` con SGAA, pero el enlace externo no

## Evolución

SGAA continuará recibiendo soporte y mantenimiento. El desarrollo estratégico de nuevas
capacidades se concentra en AuditaPy, un producto independiente que no es un despliegue de SGAA
ni comparte automáticamente su infraestructura o base de datos. La continuidad de SGAA no está
condicionada a esa evolución.

AuditaPy se plantea como una evolución técnica inspirada por la experiencia de SGAA, no como una
actualización ya desplegada. No existe una hoja de ruta pública confirmada para futuras versiones
de SGAA.
